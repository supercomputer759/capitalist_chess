# 경제 프리셋·경매·금융 자동화

로비에서 경제 프리셋을 고릅니다. 기본 선택은 스탠더드입니다.

| 프리셋 | 활성 기능 |
| --- | --- |
| 캐주얼 | 알바·월급 인상. 기존 기물 구매·포획 보상·특수 행동은 유지 |
| 스탠더드 | 기존 노동·적금·벤처·주식·부동산·신용·유지세 + 금융 자동화 |
| 풀 자본주의 | 스탠더드 + 경매장 |
| 사용자 설정 | 위 경제 기능별 ON/OFF, 기물·부동산 가격 배율 0.25~4배 |

가격 배율은 일반·특수기물 구매가, 포획 보상, 매각 가치, 경매 기본 가치, 부동산 매입가·통행료에 적용됩니다. 투자금·노동 수입과 특수 행동 가격은 기존 별도 로비 설정을 사용합니다. 궤도 캐논의 기존 활성화 설정과 가격도 유지합니다.

사용자 규칙 저장 버튼은 프리셋 규칙과 기존 로비의 초기 자금·월급·시계·AP·노동·금융·특수기물·궤도 설정을 이 브라우저에 저장합니다. 다음 로드에서 복원하며 멀티 방에서는 호스트 설정을 우선합니다. 호스트의 로비 변경과 게임 시작 설정이 스냅샷으로 양측에 전달됩니다. 시작 후에는 규칙을 변경할 수 없습니다.

## 경매장

노동·현금흐름 패널 다음의 접이식 경매장에서 사용합니다. 풀 자본주의를 선택하거나 사용자 설정에서 경매장을 켜세요.

1. 자기 비킹 기물을 선택하고 등록합니다. 시작 가격을 비우면 현재 기물 가치의 50%를 사용하며 등록에 1 AP가 듭니다. 킹 역할 특수기물도 등록할 수 없습니다.
2. 등록 즉시 판에서 제거합니다. 취소할 수 없고 네 번의 턴 전환 뒤 종료됩니다. 예를 들어 T1 등록은 T5 시작 때 정산합니다.
3. 자기 턴에 1 AP로 입찰합니다. 최초 입찰은 시작 가격 이상, 이후 입찰은 현재 가격에 $50 또는 10% 중 큰 값을 더한 금액 이상입니다. 달러 단위로 올림합니다. 판매자는 자기 경매에 입찰할 수 없습니다.
4. 입찰금은 즉시 예치합니다. 다른 입찰자로 교체되면 이전 입찰금은 반환됩니다. 현재 최고 입찰자의 추가 입찰은 받지 않습니다.
5. 낙찰되면 판매자에게 예치금을 지급하고 낙찰자의 창고로 기물을 이동합니다. 유찰되면 판매자의 창고로 돌려줍니다.
6. 창고에서 배치를 누른 뒤 자기 진영의 빈 칸을 클릭합니다. 기존 기물 구매와 같은 두 줄(백 1~2랭크, 흑 7~8랭크)에 배치하며 1 AP가 듭니다. 이동 이력·소모된 능력 횟수는 보존하고 특수기물은 다음 자기 턴부터 활성화됩니다.

게임이 먼저 끝나면 미정산 경매의 입찰 예치금을 반환하고 판매자의 창고로 기물을 돌려줍니다. 경매 등록·입찰·배치의 AP·소유권·자금·기한 검사는 호스트에서 실행합니다.

## 금융 자동화

접이식 금융 패널은 온라인에서는 자기 진영, 로컬에서는 현재 턴의 진영 설정을 보여줍니다. 각 설정은 백·흑별로 보관하며 온라인 상대의 설정을 대신 바꿀 수 없습니다. 개인 선호도 브라우저에 백·흑별로 저장합니다.

- 대출 자동 상환: 턴 시작 때 월급 20%·보유 현금·정산된 대출 잔액 중 가장 작은 금액을 갚습니다. 끄면 직접 상환할 수 있습니다.
- 이자 자동 정산: 발생 이자를 대출 잔액에 반영합니다. 꺼도 미정산 이자는 누적되고 다음 이자 계산에 포함됩니다. 직접 정산과 직접 상환은 해당 이자를 함께 처리합니다. 신용 한도에도 미정산 이자를 포함합니다.
- 만기 자동 지급: 적금·벤처의 만기 확정금을 즉시 지급합니다. 끄면 만기 당시 금액을 수령 대기금으로 보관하고 직접 수령할 수 있습니다. 반복 턴 처리로 중복 적립하지 않습니다.
- 파산 위험 알림: 현재 현금과 다음 턴의 월급·현재 유지세·예상 자동 상환을 기준으로 파산 기준에 $300 이내로 접근하면 알림을 표시합니다. 미래 기물 능력이나 시장 변동은 예측하지 않습니다.

자동화 설정 변경에는 AP가 들지 않으며 상대 턴에도 자기 설정을 바꿀 수 있습니다. 직접 수령·정산·상환도 AP는 들지 않지만 자기 턴에만 가능합니다. 자동화 기능 전체가 OFF인 프리셋에서는 기존 자동 정산·만기 지급 동작을 사용합니다.
