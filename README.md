# 자본주의 체스 v0.1.5

로컬 2인 플레이용 첫 프로토타입.

## 실행

### 그냥 게임만 할 때
`index.html`을 열어도 대부분의 기능은 동작한다.

### Stockfish까지 쓸 때 (권장)
브라우저 Worker/WASM 때문에 로컬 HTTP 서버로 여는 게 안전하다.

Windows에서는 `START_GAME.bat`을 더블클릭하면 된다.

- 턴 시작 월급 / 기물 수 세금
- 월급 인상 / 알바
- 적금 / 벤처 투자
- 5개 가상 회사 주식 / 랜덤 뉴스
- 칸 방문 횟수 / 부동산 매입 / 통행료
- 폰 즉시 승급
- 기물 즉시이동
- 킹 부활 보험
- 체크 / 체크메이트
- 파산 패배
- Stockfish 연결 훅 (엔진 파일이 있으면 최선수/탁월수 보너스)

## Stockfish 연결

`engine/` 폴더에 아래 두 파일을 넣으면 게임이 자동으로 감지한다.

- `stockfish-18-lite-single.js`
- `stockfish-18-lite-single.wasm`

브라우저용 Stockfish.js의 lite single-threaded 빌드를 기준으로 연결 코드를 작성했다.
엔진이 없으면 게임 자체는 정상 작동하고, Stockfish 보너스만 비활성화된다.

현재 보너스 기준:

- Stockfish 최선수와 동일: +$160
- 최선수이면서 포획 또는 체크: `!! 탁월수` +$350

(탁월수 판정 규칙은 나중에 더 정교하게 갈아엎을 예정.)
