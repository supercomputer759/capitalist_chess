# CATACLYSM 궤도 캐논 연출

사용자가 제공한 V16 연출을 분리한 실행 파일입니다. `index.html`을 열면 단독 미리보기가 동작하며, 기존 `orbitalcannon/CATACLYSM_V16_CAPITALIST_CHESS.html`도 같은 CSS·JS를 참조합니다. 미리보기 파일만 따로 복사하면 실행되지 않으므로 이 폴더도 함께 보관하세요.

- `cinematic.js`: 캔버스 렌더링, 사운드, 타임라인, 프레임 API
- `cinematic.css`: 연출 내부 화면
- `host.css`: 체스 게임의 전체 화면 프레임과 건너뛰기 버튼
- `../../../js/cataclysmBridge.js`: 게임과 프레임 연결

## 게임 연결

기존 실제 체스판 조준을 유지합니다. 호스트의 `executeOrbitalStrike()`가 돈·AP를 차감하고 3×3 피해와 승패를 판정한 뒤, 파괴 이전 기물 배치·실제 비용·피해 결과를 연출로 전달합니다. 게스트도 같은 결과를 받아 표시합니다. 연출 종료나 건너뛰기는 게임 결과를 다시 적용하지 않습니다.

`OrbitalBeamVfx.play(result, {muted})`가 새 연출을 실행합니다. ESC 또는 상단 버튼으로 건너뛸 수 있고, 완료하면 기존 번역된 피해 결과창을 표시합니다. 프레임 로드 실패·렌더 오류에는 기존 짧은 연출로 복구합니다. `debugOrbitalBeam("e4")`는 연출만 확인하며, 실제 발사에는 게임 내부의 `debugOrbitalStrike("e4")`를 사용합니다.

원본 타임라인은 시뮬레이션 시간 45초이며 슬로모션 때문에 실제 재생은 더 깁니다. 기존 게임 시계는 계속 흐르므로 시간제 대국에서는 건너뛰기를 사용할 수 있습니다.

## 오류 수정과 성능

삼각함수 조회표의 양수 인덱스가 720 이상이 되던 문제를 수정했습니다. 잘못된 좌표·반경은 광원 함수에서도 걸러냅니다. 큰 광원에도 캐시된 스프라이트를 사용하고 캐시 조회마다 Map을 다시 삽입하는 작업을 제거했습니다.

게임에서 재생할 때 기본 해상도 배율은 80%, 상한은 60 FPS입니다. 느린 프레임이 지속되면 해상도와 효과 품질을 단계적으로 낮춥니다. 설정창에서 해상도나 품질을 직접 고르면 자동 변경을 중단합니다. 단독 미리보기의 원래 품질 기본값은 유지합니다.

숨긴 탭은 렌더링과 소리를 멈추고 복귀 시 이어갑니다. `CATACLYSM.destroy()`는 RAF·사운드·AudioContext·관측기·전역 이벤트·캐시를 정리하며, 게임은 완료·건너뛰기·실패 시 이를 호출하고 프레임을 제거합니다. 파괴 이전/이후 체스판도 각각 캐시하여 해당 3×3 범위의 기물만 사라집니다.

추가 워커는 만들지 않았습니다. 현재 제공된 V16 파일에는 워커 코드가 없으며, 이번 변경은 광원·캔버스 해상도·렌더 수명 관리에 집중했습니다.

## 검증

`node --test --test-isolation=none tests/cataclysm.test.cjs`

캔버스 호출을 검증하는 Node VM에서 전체 타임라인, 비정상 좌표, 실제 배치·피해·비용 전달, 모서리 범위, 탭 숨김, 종료·취소·실패를 확인합니다. 실제 GPU 렌더링·FPS·호스트와 게스트의 동시 화면 검증은 별도입니다.
