# 특수기물 전용 조각

특수기물 30종의 백·흑 버전 SVG 60개입니다. 글자 배지나 외부 이모지를 사용하지 않고 각 기물의 역할을 경로로 직접 그렸습니다. 체스 말 받침과 선 두께를 공유하며, 백은 밝은 상아색, 흑은 어두운 흑연색으로 구별합니다.

- 말 탄 킹: 말 위에 왕관을 쓴 기수
- 신용카드 기사: 카드 방패를 든 말 조각
- 공장·요새·임대주택: 각각 생산 시설·성벽·주택 형태
- 저격수·판사·해적: 각각 조준경이 달린 소총·법봉·해적모와 칼
- 블랙홀·자석·거울: 궤도 고리·말굽 자석·반사면 형태

`preview.html`에서 전체 백·흑 조각을 확인할 수 있으며, `preview.png`는 SVG를 직접 렌더링한 모음 이미지입니다. 게임 보드·상점·기물 상세정보·행마 미리보기에 같은 SVG를 사용합니다. 기존 일반 기물 이미지와 게임 규칙은 유지합니다.

가짜 킹의 전용 가면 조각은 소유자와 상점에서만 표시합니다. 상대와 관전자의 보드에는 일반 킹과 동일한 이미지·크기로 표시하며, 상세정보 이미지도 위장합니다. 온라인에서는 현재 턴이 아닌 실제 접속자의 진영을 기준으로 구분합니다.

SVG 원본 도형은 `scripts/generate-special-art.cjs`에 있습니다. 프로젝트 루트에서 `node scripts/generate-special-art.cjs`로 SVG와 HTML 미리보기를 다시 생성합니다. 런타임에는 추가 라이브러리가 필요하지 않습니다. 원본 그림은 이 프로젝트를 위해 직접 작성했으며 외부 이미지나 폰트를 포함하지 않습니다.

연결부는 `js/specialPieceArt.js`에서 관리합니다. 파일 로드에 실패하면 기존 로컬 체스 이미지로 대체합니다.

검증: `node --test --test-isolation=none tests/special-art.test.cjs`
